# GTA 6 Cover Art Maker

A robust offline web application that turns any photo and caption into authentic GTA-6-style cover art. Featuring multi-panel poster layouts (3-6 angled panels), bold condensed display typography (Anton font), Vice City sunset/neon colour grading, duotone mapping, and multi-format PNG export (1080x1080, 1080x1350, 1920x1080).

## How to Run

1. Navigate to the `app/` directory:
   ```bash
   cd app
   ```
2. Start a local HTTP server:
   ```bash
   python3 -m http.server 8099
   ```
3. Open `http://localhost:8099` in your browser.
